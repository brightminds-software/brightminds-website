What Is GitHub Pages?

GitHub Pages is a free hosting service provided by GitHub that allows you to publish static websites directly from a repository.

It is widely used for portfolios, documentation, landing pages, and learning projects.

Why Use GitHub Pages?

  • 100% Free hosting
  • No ads
  • Perfect for HTML, CSS & JavaScript
  • Trusted by developers worldwide

What You Need Before You Start

  1. A GitHub account
  2. A simple website (HTML, CSS, JS)
  3. Internet connection

Step 1: Create a GitHub Account

Visit github.com and sign up for a free account. Use a professional username — it will represent your brand.

Step 2: Create a New Repository

After logging in:

  1. Click the “+” icon
  2. Select “New repository”
  3. Name it (e.g. my-website)
  4. Set it to Public

Step 3: Upload Your Website Files

Upload your index.html file first. GitHub Pages requires this file to load your website.

You can upload files directly or push them using Git.

Step 4: Enable GitHub Pages

  1. Open repository Settings
  2. Click Pages
  3. Select main branch
  4. Save changes

Your Website Is Now Live 🎉

GitHub will generate a link like:

https://username.github.io/repository-name

GitHub Pages Limitations

  • No backend (PHP, Node.js)
  • Static sites only
  • Not ideal for large businesses

Who Should Use GitHub Pages?

GitHub Pages is perfect for:

  • Students
  • Beginners learning web development
  • Portfolio websites
